## 1) Reminders.kt —— 「测试提醒」的发通知函数（当时加在 ensureChannel 后面）

```kotlin
    /** 「测试提醒」按钮用：**立刻**发一条通知。 */
    fun postTest(context: Context) {
        ensureChannel(context)
        val n = NotificationCompat.Builder(context, CHANNEL_ID)
            .setSmallIcon(android.R.drawable.ic_dialog_info)
            .setContentTitle(AppCtx.s(R.string.notify_test_title))
            .setContentText(AppCtx.s(R.string.notify_test_text))
            .setAutoCancel(true)
            .build()
        (context.getSystemService(Context.NOTIFICATION_SERVICE) as NotificationManager)
            .notify(999001, n)
    }
```

## 4) 文案（4 个语言包各一套，用 `values/values-zh-rTW/values-zh-rHK/values-en`）

简中版：

```xml
<string name="settings_test_reminder_title">测试提醒</string>
<string name="settings_test_reminder_desc">点一下立刻发一条测试通知 —— 只用来确认通知通不通，跟你的数据没关系</string>
<string name="notify_test_title">测试提醒</string>
<string name="notify_test_text">看到这条，说明通知是通的；到点就会这样响</string>
<string name="settings_alarm_status_title">闹钟状态</string>
<string name="alarm_info_ok">已定 %1$d 条，最近一条 %2$s</string>
<string name="alarm_info_none">一条都没定上 —— 检查：截止日填了吗？状态是不是「进行中」？算出来的时间是不是已经过去了？</string>
<string name="alarm_info_disabled">提醒开关是关着的，所以没定</string>
```

⚠️ 英文包里**不能有未转义的单引号**（`'`）—— aapt2 会报
`Invalid unicode escape sequence in string`。当时写成 `Doesn't` 就编译不过，
改成 `Nothing to do with your data.` 才对（或者写 `\'`）。
