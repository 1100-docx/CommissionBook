# 已撤掉：导出 Excel 报表（2026-10-07，双端）

逸风原话：**「算了，撤掉这个功能，双端」**（2026-10-07 11:4x）。

## 为什么撤

功能是当天上午加的（他：「加入导出Excel报表功能吧，双端都做」，朋友也赞成）。
做出来之后连着两轮卡在「**手机上打开是空的**」：

1. 第一轮：合计那三格空白 —— 我们只往文件里写了公式、没写算好的结果，
   手机上的表格预览器不执行公式 → 空白。修法：公式带上缓存值（`cached`）+ `fullCalcOnLoad`。
2. 第二轮：安卓导出的**整个文件是 0 字节** —— 老代码把拼好的字节先攒在 Activity 的字段里，
   系统「存到哪」弹窗期间 App 被回收重建 → 字段没了，可文件已经被系统建好了 → 留下空文件。
   修法：字节在 ActivityResult 回调里**现算**，写完读回来核对。

两轮都修完、版式也按他要的改成竖排之后，他还是决定**不要了**（大概是折腾够了）。
这不是技术问题，是产品决定 —— 别再劝他装回来，除非他自己提。

## 血泪点（重做时别再踩）

- **不装第三方库**：`.xlsx` 自己拼（ZIP 走 STORE 不压缩 + 5 份 XML + 字符串走 `inlineStr` + 数字写真数字）。
  Apache POI 那一套会把包从 2.2MB 顶到 10MB+。
- **公式必须带缓存值**（`Cell.Formula(v, cached)`）：不带的话 Excel/WPS 会算、手机预览器不算 → 一片空白。
  workbook 里再加 `<calcPr calcId="0" fullCalcOnLoad="1"/>`，让真算的地方按公式来。
- **必须写 `<dimension ref="A1:K…"/>`**，而且要在 `<cols>` 前面：手机预览器照它决定画多大网格。
- **版式**（他拿截图定的）：合计**竖排四行放在最上面**（合计条数 / 总价合计 / 已付合计 / 未付合计，
  名字在 A 列、数字在 B 列）→ 第 5 行表头 → 数据从第 6 行起，公式是 `SUM(D6:D…)`。
  （中间做过一版「横排一行」，被否了。）
- **只导「当前模式」那一本**（买家 / 画师分开）；当前这本是空的时候**先提示、别导**，
  否则用户拿到一张只有表头的空表，会以为功能坏了。
- **安卓：`registerForActivityResult` 的回调里，数据要现算**。凡是「先攒进字段、等回调回来再用」的写法，
  都可能因为 App 在系统弹窗期间被回收重建而变成 `null` → **系统已经把文件建好了，我们却写不进去
  → 留下 0 字节空文件，还不报错**。（同一个坑当时也埋在 JSON 备份导出上，一起修了：
  现在备份也是在回调里现算 `state.toJsonString()`。）
- **写完要读回来核对**（`Backup.writeBytes` 就是这么干的：长度 + 内容都一样才算成功，
  返回真实字节数），提示改成「已保存 · N KB」—— 以后再有「是不是空的」这种疑问，看这一句就知道。
- 英文文案里的撇号 `'` 在安卓 XML 里必须写 `\'`，否则 aapt2 报
  `Invalid unicode escape sequence in string`。

## 验证方式（这套以后还用得上）

`.kt` 那两份是纯逻辑，可以脱离 Android 单独跑：

```bash
# 用 Gradle 缓存里的 kotlin 编译器单独编一份（⚠️ 本机默认 java 是 JDK 27，
# Kotlin 2.0.21 解析 java.version=27 会直接抛 IllegalArgumentException: 27，必须显式用 21）
J=/opt/homebrew/opt/openjdk@21/bin/java
L=~/.gradle/wrapper/dists/gradle-8.13-bin/*/gradle-8.13/lib
CP=$(ls $L/*.jar | grep -Ei "kotlin|coroutin|trove|annotations" | tr '\n' ':')
$J -cp "$CP" org.jetbrains.kotlin.cli.jvm.K2JVMCompiler -no-stdlib -no-reflect \
   -cp "$L/kotlin-stdlib-2.0.21.jar" -d out XlsxWriter.kt 你的脚手架.kt
$J -cp "out:$L/kotlin-stdlib-2.0.21.jar" 你的脚手架Kt
```

再用 **openpyxl** 读回来核对（表名 / 列数 / 数字类型 / 公式 / 转义 / 缓存值 / dimension）。
报表这种文件最怕「看着像那么回事、一开就报错」。
